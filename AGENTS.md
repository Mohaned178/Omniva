# Omniva

A connected Personal Life Management Platform. Approved product and design decisions live in
`omniva-product-definition.html`, `omniva-system-design.html`, `GLOSSARY.md` and `docs/adr/`.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `Mohaned178/Omniva`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
