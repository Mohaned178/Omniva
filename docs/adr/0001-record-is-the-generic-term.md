# "Record" is the generic term; "Item" is one building block

The approved product documents used "item" both for the possession building block and for any entry in Omniva. We decided that **Record** means any entry of any building block, and **Item** means only the possession block (car, laptop, apartment). This keeps the domain model, code and specifications from treating a passport (a Document) or a subscription (an Obligation) as an Item.
